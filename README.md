# Python Practice

This repository is a collection of Python exercises, assignments, and examples organized into topic folders. It is not packaged as one application and has no single entry point or shared dependency list.

## Requirements

- Python 3
- Additional packages may be required by individual exercises; there is no repository-wide dependency manifest.

## Run an exercise

Choose a `.py` file and run it from this repository directory:

```bash
python path/to/exercise.py
```

Some exercises may prompt for input or require packages that are not used elsewhere in the repository.

## Tests

No automated test suite is configured. Run exercises individually and verify their output for the supplied inputs.
